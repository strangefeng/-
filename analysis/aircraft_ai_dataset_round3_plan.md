# Aircraft AI Dataset 第三轮实验计划

## 1. 目标

第三轮目标不是继续发散式试模块，而是将第二轮中“高分辨率对小目标更友好”的弱正信号，转化为能够支撑论文主创新的稳定结果。

本轮遵循以下原则：

- 以第二轮最优 `R1` 作为结构与训练底座
- 只做小目标友好、低扰动、可部署的轻量改进
- 不再回到 WT/NWD 的复杂复合改造路线

## 2. 实验矩阵

第三轮锚点与新实验如下：

| 编号 | 配置 | 角色 |
| --- | --- | --- |
| `B0` | YOLO11n @640 | 全局基线锚点（沿用第一轮结果） |
| `R1` | YOLO11n @800 | 第三轮对照底座（沿用第二轮结果） |
| `T1` | `R1 + P2 head` | 第三轮主实验，验证小目标友好结构 |
| `T2` | `R1 + P2 + ECA` | 条件执行，验证单点轻量注意力补强 |

其中：

- `B0` 与 `R1` 不重复训练，直接沿用前两轮已完成结果
- 第三轮正式新增训练任务为 `T1`
- 若 `T1` 对 `R1` 呈现正信号，则自动继续执行 `T2`

## 3. 成功判据

### 判据 A

`T1` 的 `mAP50-95` 稳定高于 `R1`，最好也高于 `B0`

### 判据 B

即使总体提升有限，`missing-rivet AP50-95` 也应有明确正向提升，同时总体指标不明显下降

### 判据 C

模型参数量、FLOPs、推理开销和导出能力不能显著恶化，仍需保持部署友好

## 4. 自动执行策略

自动化流程如下：

1. 检查并读取第一轮 `B0` 与第二轮 `R1` 的结果作为锚点
2. 运行 `T1`
3. 将 `T1` 与 `R1` 比较：
   - 若 `mAP50-95` 提升，或
   - `missing-rivet AP50-95` 提升且总体 `mAP50-95` 未明显下降
4. 满足条件时继续运行 `T2`
5. 输出第三轮汇总页，统一比较 `B0 / R1 / T1 / T2`

## 5. 评价重点

第三轮重点关注：

- `mAP50-95`
- `mAP50`
- `Recall`
- `missing-rivet AP50-95`
- `scratch AP50-95`
- 参数量 / FLOPs / 模型大小 / 推理速度 / ONNX 可导出性

## 6. 预期结论形式

第三轮希望得到以下两类结论之一：

- 结论 1：`P2` 小目标头在 800 分辨率输入下可以稳定提升 `missing-rivet` 与总体表现
- 结论 2：`P2` 有效，但继续叠加注意力收益有限，从而证明“高分辨率 + 小目标头”已是更合适的工程折中方案
