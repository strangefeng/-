# round13 第一批实验正式结论

## 1. 实验目的

第十三轮第一批实验围绕 `round12` 中最接近最优基线 `N2` 的切片训练候选 `S2` 展开，核心目标是验证：在保持 `YOLO11n + imgsz=800 + 关闭 mosaic/erasing 等强增强` 这一细节保真训练主线不变的前提下，是否可以通过切片策略修正进一步提升模型性能，并最终超过当前最优基线 `N2`。

结合前期实验结果可以发现，`S2` 的 `mAP50` 与 `Recall` 均高于 `N2`，说明切片训练能够提高微小缺陷的检出能力，但其 `mAP50-95` 仍低于 `N2`，表明切片方案虽然增强了召回，却没有同步改善高 IoU 阈值下的定位质量与类别稳定性。因此，`round13` 第一批实验的重点不再是扩展新结构，而是对切片训练和切片推理进行针对性修正。

本批实验共包括四项内容：`E1` 切片推理阈值搜索、`E2` 整图与切片融合推理评估、`R13-S2a` 单尺度 `640` 切片训练，以及 `R13-S2b` `512+640` 多尺度切片训练。

---

## 2. 对比基线

当前全流程最优基线为 `N2`，其关键指标如下：

- `mAP50 = 0.744904`
- `mAP50-95 = 0.352565`
- `Precision = 0.782191`
- `Recall = 0.706429`
- `missing-rivet AP50-95 = 0.306116`
- `rust AP50-95 = 0.401327`
- `scratch AP50-95 = 0.350252`

`round12` 中最接近 `N2` 的新方案为 `S2`，其指标为：

- `mAP50 = 0.759635`
- `mAP50-95 = 0.344840`
- `Precision = 0.773454`
- `Recall = 0.733010`
- `missing-rivet AP50-95 = 0.299891`
- `rust AP50-95 = 0.383286`
- `scratch AP50-95 = 0.351343`

因此，`round13` 的判断标准主要有两个：一是能否超过 `N2` 的 `mAP50-95 = 0.352565`；二是能否在保持或接近 `S2` 检出能力优势的同时，改善定位质量和难类稳定性。

---

## 3. 切片推理实验结果分析

### 3.1 E1：SAHI 切片推理阈值搜索

`E1` 的目的是检验 `round12` 中 `S1` 的失败是否主要由过低置信度阈值导致。实验对不同 `conf` 与 `merge_iou` 参数组合进行了搜索，结果表明最优组合为：

- `conf = 0.05`
- `merge_iou = 0.50`

对应指标为：

- `Precision = 0.232810`
- `Recall = 0.530213`
- `mAP50 = 0.312862`
- `mAP50-95 = 0.114130`

该结果说明，尽管适当提高阈值后误检问题较 `round12` 的极低阈值设置有所缓解，但切片推理的整体表现仍然显著低于 `N2`。其根本原因在于，飞机蒙皮表面存在大量与缺陷形态相似的正常纹理信息，例如铆钉、接缝、反光和涂层变化区域。切片推理在缺乏足够全局上下文的情况下，容易将这些局部纹理误识别为缺陷候选区域，从而导致精度不足。

因此可以认为，`round12` 中 `S1` 的失败并不完全是阈值设置问题，切片推理本身在当前公开三分类飞机蒙皮数据集上就存在较明显的误检放大效应。

### 3.2 E2：整图、切片与融合推理对比

`E2` 的目的是评估整图推理、切片推理以及二者融合推理在部署场景中的可行性。结果如下：

- `E2-1 (N2 full)`: `mAP50-95 = 0.310946`
- `E2-2 (N2 slice)`: `mAP50-95 = 0.102519`
- `E2-3 (N2 fused)`: `mAP50-95 = 0.270185`
- `E2-4 (S2 full)`: `mAP50-95 = 0.291685`
- `E2-5 (S2 slice)`: `mAP50-95 = 0.123530`
- `E2-6 (S2 fused)`: `mAP50-95 = 0.258578`

从结果看，单独切片推理依然最差，整图推理优于切片推理，而整图与切片融合推理虽然在部分组合中带来了一定召回补偿，但仍未达到可替代主线模型的程度。换言之，在当前任务设置下，切片推理无法同时兼顾误检控制与检测精度，即使与整图推理进行后融合，也没有表现出足够稳定的增益。

这一结果说明，切片策略更适合作为训练阶段的信息增强手段，而不是直接作为部署阶段的主推理策略。

---

## 4. 切片训练实验结果分析

### 4.1 R13-S2a：640 切片训练

`R13-S2a` 的设计动机是修正 `S2` 中 `512` 切片可能带来的上下文不足问题。实验将训练切片尺度由 `512` 提高到 `640`，其结果为：

- `mAP50 = 0.725520`
- `mAP50-95 = 0.335114`
- `Precision = 0.770644`
- `Recall = 0.697565`
- `missing-rivet AP50-95 = 0.285296`
- `rust AP50-95 = 0.382908`
- `scratch AP50-95 = 0.337138`

与 `N2` 相比，`R13-S2a` 在综合指标和各类别指标上均未取得提升；与 `S2` 相比也出现了进一步下降。这说明单纯增大切片尺寸虽然在理论上可能保留更多局部上下文，但同时也削弱了微小缺陷在输入图像中的相对像素占比，使得切片训练原本对小目标检出的优势被部分抵消。

因此，`640` 单尺度切片并未证明比 `512` 更适合当前飞机蒙皮细粒度缺陷检测任务。

### 4.2 R13-S2b：512+640 多尺度切片训练

`R13-S2b` 的设计目的是在 `512` 与 `640` 两种尺度之间寻求互补，即用较小切片强化微小缺陷和弱纹理目标的检出，用较大切片补充局部上下文信息。实验结果如下：

- `mAP50 = 0.741452`
- `mAP50-95 = 0.341361`
- `Precision = 0.791501`
- `Recall = 0.703119`
- `missing-rivet AP50-95 = 0.297033`
- `rust AP50-95 = 0.377667`
- `scratch AP50-95 = 0.349382`

与 `R13-S2a` 相比，`R13-S2b` 确实取得了更好的综合表现，说明双尺度切片训练比单独 `640` 切片更合理；但与 `S2` 相比，其 `mAP50-95` 仍下降了 `0.003479`，与 `N2` 相比则下降了 `0.011204`。从类别上看，`missing-rivet`、`rust` 和 `scratch` 三类缺陷均未超过 `N2`，其中 `rust` 类下降尤为明显。

这一结果表明，多尺度切片虽然在一定程度上平衡了小目标检出与上下文保留，但仍未从根本上解决切片训练在高 IoU 阈值下定位不稳、类别边界不够清晰的问题。

---

## 5. round13 第一批总体结论

综合 `E1`、`E2`、`R13-S2a` 和 `R13-S2b` 的结果，可以得到以下正式结论：

1. 切片推理不适合作为当前任务的主部署推理方式。即使通过阈值搜索和整图融合进行修正，切片推理仍然无法在误检控制与综合精度之间取得理想平衡。
2. 切片训练相较于切片推理更有研究价值，但本轮实验表明，无论是单尺度 `640` 切片训练还是 `512+640` 多尺度切片训练，都未能超过 `round12` 的 `S2` 候选，更未能超过当前最优基线 `N2`。
3. `R13-S2b` 是本批实验中表现最好的新候选，但其 `mAP50-95 = 0.341361` 仍低于 `S2 = 0.344840` 和 `N2 = 0.352565`，因此不足以替代现有主线模型。
4. 本轮实验进一步证明，当前公开飞机蒙皮三分类数据集上的性能提升已经不再取决于简单改变切片尺度或增加切片层级，而更可能受限于定位质量、边界框回归精度以及背景纹理误检抑制能力。

因此，`round13` 第一批实验的最终结论是：

> 在飞机蒙皮细粒度缺陷检测任务中，单纯围绕切片尺度与切片组合方式进行修正，尚不足以使切片训练路线超过 `N2` 主线。当前最优模型仍然是基于整图训练的 `N2`，即 `YOLO11n + imgsz=800 + 关闭 mosaic/erasing 等破坏细节的强增强`。

---

## 6. 对后续实验的启示

`round13` 第一批实验虽然没有产生新的最优模型，但其结果对后续研究方向具有明确指向意义：

1. 后续如继续沿切片路线优化，不应再优先扩大切片尺度或简单叠加多尺度切片，而应转向改善定位质量的损失函数设计，例如 `Focaler-IoU` 一类更关注高 IoU 阈值回归质量的边界框损失。
2. 若从工程部署角度出发，应更加关注误检抑制与背景纹理区分能力，因此困难负样本增强比继续扩展切片推理更有现实意义。
3. 从论文主线角度看，`round13` 第一批的负结果进一步强化了全文结论：对于飞机蒙皮小缺陷检测任务，细节保真的训练策略比复杂输入组织和后处理组合更关键。

基于以上结果，后续实验的重点应转向：在最佳候选模型基础上进行定位损失改进与 hard negative 约束，而不是继续对切片尺寸和切片推理方式进行横向扩展。
