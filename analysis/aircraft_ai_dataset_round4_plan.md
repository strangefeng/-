# Aircraft AI Dataset 下一轮实验计划

## 1. 目标

前几轮结果表明：

- 复杂结构改造（WT/NWD）无收益
- `P2` 小目标头无收益
- `rect=True` 无收益
- `800` 分辨率、官方结构、`rect=False` 的 `R1` 仍是当前最稳的最佳配置

因此，下一轮不再改模型结构，而是围绕 `R1` 做训练策略优化，重点验证默认增强是否在破坏小缺陷、弱纹理和细长目标的表征。

## 2. 实验矩阵

本轮保留两个历史锚点，不重复训练：

- `B0`: 第一轮官方基线锚点
- `R1`: 第二轮最优锚点

本轮新增 4 组训练策略实验：

| 编号 | 配置 | 作用 |
| --- | --- | --- |
| `N1` | `R1 + weak_aug` | 验证整体弱增强是否更适合弱纹理缺陷 |
| `N2` | `R1 + no_mosaic_no_erasing` | 单独验证去掉 `mosaic/erasing` 是否能保住缺陷细节 |
| `N3` | `R1 + weak_aug + no_mosaic` | 验证“弱增强 + 去 mosaic”组合是否优于单项调整 |
| `N4` | `N3 + longer_schedule` | 在最保守增强策略上延长训练，验证是否能进一步稳定收敛 |

## 3. 设计理由

当前 `R1` 使用的默认增强较强：

- `mosaic=1.0`
- `erasing=0.4`
- `auto_augment=randaugment`
- `scale=0.5`
- `translate=0.1`
- `hsv_s=0.7`
- `hsv_v=0.4`

这类增强对通用目标检测有帮助，但对飞机蒙皮缺陷这种依赖局部微弱纹理、形态连续性和细长边界的任务，可能会产生负作用。

## 4. 成功判据

- 总体 `mAP50-95` 高于 `R1`
- 或 `missing-rivet AP50-95` 明显提升，且总体指标不显著下降
- 推理速度、模型规模保持与 `R1` 同量级

## 5. 重点指标

- `mAP50`
- `mAP50-95`
- `precision`
- `recall`
- `missing-rivet AP50-95`
- `rust AP50-95`
- `scratch AP50-95`

## 6. 预期输出

输出一页汇总报告，统一比较：

- `B0`
- `R1`
- `N1`
- `N2`
- `N3`
- `N4`

并明确给出“下一轮训练策略是否优于当前最优 `R1`”的结论。
