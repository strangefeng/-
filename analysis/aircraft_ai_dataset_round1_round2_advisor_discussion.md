# Aircraft AI Dataset 两轮实验对比与导师讨论结论

## 1. 当前进展概述

基于公开数据集 `Aircraft AI Dataset.v1i.yolov11`（对应论文 *Advances in Aircraft Skin Defect Detection Using Computer Vision: A Survey and Comparison of YOLOv9 and RT-DETR Performance* 中的 Dataset I），目前已经完成两轮实验：

- 第一轮：验证官方 `YOLO11n` baseline 与若干结构改进方案（WT/NWD 系列）
- 第二轮：围绕第一轮结论，转向更保守的高分辨率与训练策略实验

## 2. 第一轮与第二轮当前最优结果对比

### 2.1 第一轮最优

第一轮最优模型为官方 `YOLO11n` baseline，即 `B0`：

- 实验编号：`B0`
- 标题：`Official YOLO11n baseline`
- 训练设置：`640x640`，`100 epochs`，`batch=16`
- 结果：
  - `Precision = 0.792231`
  - `Recall = 0.701870`
  - `mAP50 = 0.753719`
  - `mAP50-95 = 0.350426`
  - `missing-rivet AP50-95 = 0.302157`
  - `rust AP50-95 = 0.402333`
  - `scratch AP50-95 = 0.346787`

### 2.2 第二轮最优

第二轮最优模型为 `R1`，即提升输入分辨率后的高分辨率 baseline：

- 实验编号：`R1`
- 标题：`Higher-resolution baseline at 800`
- 训练设置：`800x800`，`100 epochs`，`batch=12`
- 结果：
  - `Precision = 0.778088`
  - `Recall = 0.706005`
  - `mAP50 = 0.751459`

  - `scratch AP50-95 = 0.347015`

### 2.3 当前最佳对比结论

将第一轮最优 `B0` 与第二轮最优 `R1` 直接比较：

| 指标 | B0 (640) | R1 (800) | 差值 (R1-B0) |
| --- | ---: | ---: | ---: |
| Precision | 0.792231 | 0.778088 | -0.014143 |
| Recall | 0.701870 | 0.706005 | +0.004135 |
| mAP50 | 0.753719 | 0.751459 | -0.002260 |
| mAP50-95 | 0.350426 | 0.351250 | +0.000824 |
| missing-rivet AP50-95 | 0.302157 | 0.310734 | +0.008577 |
| rust AP50-95 | 0.402333 | 0.396002 | -0.006331 |
| scratch AP50-95 | 0.346787 | 0.347015 | +0.000228 |

可以看出：

- `R1` 在更严格的 `mAP50-95` 上略高于 `B0`
- `R1` 对 `missing-rivet` 小目标类有相对更明显的正向作用
- 但 `R1` 的 `mAP50` 略低于 `B0`
- 总体增益幅度非常小，还不足以支持“第二轮已经取得明确提升”的结论

因此，目前最稳妥的说法是：

**第二轮验证了“适度提升输入分辨率”是一个比 WT/NWD 结构改造更有希望的方向，但当前增益仍然有限，尚未形成显著优势。**

## 3. 第一轮实验结论

第一轮共完成 7 组实验，核心任务是检验 WT/NWD 系列结构改进是否能在该 3 类公开数据集上优于官方 baseline。结果显示：

- `B0` 官方 baseline 反而是第一轮最优
- 所有结构增强组均未超过 `B0`
- 最好的结构增强组 `M3` 仍明显低于 `B0`

这说明：

1. 官方 `YOLO11n` 在该数据集上已经是一个较强基线
2. 当前 WT/NWD 改造路线与该数据集分布不够匹配
3. 继续深挖这条复杂结构路线，时间成本较高，成功概率较低

第一轮最重要的价值不是“得到了提升”，而是**有效排除了不适合当前任务的数据-模型组合方向**。

## 4. 第二轮实验结论

第二轮转向更轻、更保守的方案，共完成 3 组实验：

- `R1`: `800` 分辨率默认训练
- `R2`: `800` 分辨率 + 保守增强
- `R3`: `960` 分辨率 + 保守增强

结果显示：

- `R1` 为第二轮最优
- `R2` 不如 `R1`，说明这套“保守增强”没有带来收益
- `R3` 也不如 `R1`，说明继续把分辨率推到 `960` 并没有形成进一步提升

这说明第二轮已经给出一个很清晰的信号：

1. “高分辨率轻改动”是可行方向
2. 但不是分辨率越高越好
3. 训练增强策略并不是当前主要瓶颈
4. 当前更值得关注的是“如何在不破坏官方结构稳定性的前提下，专门改善小目标表达”

## 5. 当前适合向导师汇报的总体判断

可以向导师明确汇报以下几点：

### 5.1 这个公开数据集可以作为论文 baseline 数据集

理由是：

- 来自公开论文，来源规范
- 类别定义清晰，数据划分明确
- 本地复现实验能够稳定复现合理结果
- 两轮实验已经证明它适合承载 baseline、消融和后续改进实验

### 5.2 官方 YOLO11n 是当前可信 baseline

第一轮已经证明，复杂结构改进没有超过官方 baseline；第二轮也证明，即便转向高分辨率轻改动，当前优势也只是非常小的边际改进。因此，`B0` 仍然可以被视为当前最稳的 baseline 锚点。

### 5.3 第二轮不是失败，而是成功缩小了后续搜索空间

第二轮至少说明两件事：

- 改进方向应该更保守、更贴近小目标问题本身
- 后续不应继续扩展“重结构复合改造”，而应优先尝试对官方结构扰动更小、但对小目标更友好的方法

## 6. 建议的后续方向

基于当前两轮实验结果，建议第三轮不要再做大范围发散，而是只保留最有希望的 2 到 3 个方向。

### 方向 A：基于 R1 的小目标友好结构微调

建议优先考虑：

- 增加 `P2` 小目标检测头
- 或者引入更轻量的小目标特征分支

原因：

- 当前 `R1` 对 `missing-rivet` 已经有正向提升
- 说明提高小目标可见像素是有效的
- 下一步最自然的延伸就是进一步增强小目标检测能力

### 方向 B：保持官方主干不变，仅做轻量注意力增强

建议：

- 不改 backbone 主体
- 只在 neck 或浅层融合位置加入一个轻量注意力模块

原因：

- 第一轮已经证明大结构改动风险高
- 如果还希望在 `scratch` 和 `rust` 上提升，应尽量采用低风险、低侵入式方案

### 方向 C：做更公平的输入流程对比

建议：

- 后续若能拿到更接近原始比例的数据版本，可比较 `stretch` 与 `letterbox/保比例输入`

原因：

- 当前 Roboflow 导出带有 `640x640 stretch`
- 这可能已经改变了目标几何形态
- 对细长缺陷和小目标都可能有影响

## 7. 建议给导师的讨论结论

可以直接使用下面这段作为汇报草稿：

“目前基于公开 Aircraft AI Dataset 已完成两轮实验。第一轮以官方 YOLO11n 作为 baseline，并测试了一系列 WT/NWD 结构改进，结果显示所有复杂结构改进均未超过官方 baseline，说明该数据集上官方模型已经较强，且重结构路线不适合作为当前主攻方向。第二轮进一步转向更保守的高分辨率与训练策略实验，结果表明 800 分辨率的高分辨率 baseline 在 mAP50-95 上略优于第一轮 baseline，并且对 missing-rivet 小目标类别有更明显提升，但整体增益仍然较小，尚不足以形成显著优势。综合来看，该公开数据集可以作为论文 baseline 数据集，当前最合理的后续方向是围绕官方 YOLO11n 进行小目标友好的轻量改进，例如 P2 小目标头或低侵入式注意力增强，而不再继续深挖 WT/NWD 复合结构路线。” 

## 8. 当前结论一句话版

**数据集可作为 baseline；官方 YOLO11n 仍是当前最稳基线；第二轮说明高分辨率轻改动比重结构更有前途；下一步应聚焦小目标友好的轻量增强，而不是继续做复杂结构叠加。**
