# round1-round11 最终总实验结论 + 论文主线建议

## 1. 总体一句话结论

如果把 `round1` 到 `round11` 看成一条连续优化链，那么最稳定、最可解释、最适合写入论文主线的最终结论是：

1. 对当前 `Aircraft AI Dataset` 三分类任务，**最有效的提升并不来自复杂结构改造**，而是来自**更贴合缺陷细节保真的训练策略调整**。
2. 在全部实验中，**`N2`（800 输入分辨率 + 关闭 mosaic / erasing / 强自动增强）是综合性能最优、稳定性最好、工程代价最低的最终主线模型**。
3. 后续大量实验进一步证明：**复杂结构增强、小目标检测头、注意力模块、跨模型替换、针对性清洗、类别过采样**等方向，虽然有局部动机，但都**没有稳定超过 `N2`**。
4. 因此，这组实验最强的论文价值，不是“提出了一个越来越复杂的新模型”，而是**系统证明了：在飞机蒙皮细粒度缺陷检测场景中，细节保真比结构堆叠更关键，轻量模型配合合适训练策略优于复杂改造路线**。

这其实是一个很完整、也很适合毕业论文的主线。

## 2. 最终推荐主线模型

### 最终主线模型

- 模型：`YOLO11n`
- 输入尺寸：`800`
- 训练策略：基于 `R1`，关闭 `mosaic`、`erasing`，不走激进自动增强
- 最终命名锚点：`N2`

### `N2` 关键指标

- `mAP50 = 0.744904`
- `mAP50-95 = 0.352565`
- `Precision = 0.782191`
- `Recall = 0.706429`
- `missing-rivet AP50-95 = 0.306116`
- `rust AP50-95 = 0.401327`
- `scratch AP50-95 = 0.350252`

### 为什么最终选 `N2`

不是因为它在每个单项指标上都绝对最高，而是因为它满足了论文主线最需要的四个条件：

1. **综合指标最优**
   - `N2` 是全流程里 `mAP50-95` 最高的模型。
2. **结论稳定**
   - 从 `round5` 到 `round11`，几乎所有后续路线都没能稳定超越它。
3. **解释顺**
   - 其核心思想非常明确：对细粒度、小目标、弱纹理缺陷，过强的数据增强会破坏判别细节。
4. **工程上可信**
   - 不依赖复杂新模块，不依赖大模型，不依赖额外推理负担，更像真实可复现、可部署的方案。

## 3. round1-round11 总体演化逻辑

整个实验过程可以压缩成四个阶段：

### 阶段一：建立基线，确认“结构堆叠”不是答案（round1）

`round1` 做了两件事：

1. 建立公开三分类数据集上的 `YOLO11n` 官方基线 `B0`
2. 初步测试多个结构改造方向，如 `WTConv`、`NWD loss`、协同监督、Rep neck 等

结果非常明确：

- `B0` 的 `mAP50-95 = 0.350426`
- 多个结构改造模型全部低于 `B0`
- 最差的 `M1` 甚至降到 `0.281306`

这一步的价值很大，因为它提前排除了一个很常见但容易失控的路线：**不是简单加模块就能提升这类缺陷检测任务**。

### 阶段二：确认提升来自“分辨率与增强策略”，而不是网络变复杂（round2-round4）

这三轮是整条主线里最关键的增益阶段。

#### round2：提高输入分辨率

`R1` 将输入提高到 `800`，在保持官方训练框架的前提下得到：

- `mAP50-95 = 0.351250`

和 `B0` 相比：

- `+0.000824`

绝对提升不大，但方向很重要：**更高分辨率对小缺陷是有效的**。

同时，`R2`、`R3` 说明：

- 不是“增强越保守越好”
- 也不是“分辨率越高越好”
- `960` 并没有继续带来提升，反而有优化稳定性和收益递减问题

所以 round2 的结论是：

- **800 是一个合理的细节分辨率平衡点**

#### round3：尝试加 P2 小目标检测头

按直觉看，`missing-rivet` 这类目标很小，给模型加 `P2` 检测头似乎应该有效。

但实际结果：

- `T1 mAP50-95 = 0.236019`
- 相比 `R1`，下降 `0.115231`

这是全流程里一个非常重要的“反直觉证据”：

- 当前数据分布下，**小目标头并没有带来稳定收益**
- 反而显著破坏整体检测性能

这说明问题不只是“目标小”，更可能是：

1. 数据质量和纹理特征本身脆弱
2. 增强和结构改造可能打乱了原本较稳定的特征表达

#### round4：回到训练策略本身，得到最终最优 `N2`

`round4` 是主线真正成型的地方。

核心比较：

- `N1`：弱增强
- `N2`：关闭 mosaic + erasing
- `N3`：弱增强 + no mosaic
- `N4`：延长训练

结果显示：

- `N2 mAP50-95 = 0.352565`
- 比 `R1` 提升 `+0.001315`
- 比 `B0` 提升 `+0.002139`

虽然提升数值不算夸张，但意义非常强：

1. 它是**全链路最高分**
2. 它的提升来自**训练策略与任务特征的匹配**
3. 它证明：**对飞机表面细粒度缺陷检测，mosaic、erasing 这类会破坏局部纹理与几何细节的增强，并不适合作为默认配置**

到这里，其实论文的核心方法结论已经成立了。

### 阶段三：验证数据预处理与标签清洗路线是否还能继续提升（round5-round8）

这一阶段的主线不是找新模型，而是验证：

- 数据导出方式改造有没有帮助
- 标签清洗有没有帮助
- focus-crop / targeted cleanup 有没有帮助

#### round5：fit-within 导出策略

最好的实验是 `F2`：

- `mAP50-95 = 0.349023`
- 比 `N2` 低 `0.003542`
- 但 `missing-rivet AP50-95` 比 `N2` 略高 `+0.002356`

这说明：

1. `fit-within` 并没有带来综合性能反超
2. 但它对**极小缺陷类**有一定帮助

因此 round5 最适合在论文里写成：

- **一种有局部价值的数据预处理补充方案**
- 而不是主线最终方案

#### round6：focus-crop / 清洗增强分支

这一轮整体表现都不如 `N2`。

最好的是 `C1`：

- `mAP50-95 = 0.337972`
- 比 `N2` 低 `0.014593`

这说明：

1. 单纯 focus-crop 或裁剪增强，并没有带来预期收益
2. 过于改变原始图像分布，可能削弱模型对真实场景的泛化
3. 数据清洗如果和“裁剪重构”绑得太紧，收益会被副作用抵消

#### round7：扩大 targeted cleanup

`G2` 是 round7 最好的结果：

- `mAP50-95 = 0.347892`
- 比 `N2` 低 `0.004673`

但相对 round6 明显回升，说明一件事：

- **清洗本身是有价值的**
- 问题不在“清洗”这件事，而在于之前把清洗和 focus-crop 强绑定了

这一步的实验价值是：

- 将“标签质量问题存在”这个判断坐实
- 同时也说明，标签清洗的收益仍然**不足以稳定超过训练策略最优解**

#### round8：进一步扩大 train-only targeted cleanup

`H1`、`H2` 都没有超过 `G2`，更没有超过 `N2`。

其中最好的是 `H2`：

- `mAP50-95 = 0.339661`
- 比 `N2` 低 `0.012904`

这轮基本可以下最终判断：

- **公开三分类数据集在现有定义下已经接近收益饱和**
- 继续做小规模 targeted cleanup，边际收益非常有限

所以 round5-round8 最后共同支撑出的结论是：

1. 数据预处理和标签清洗不是完全无用
2. 但它们更像局部修补，不足以推翻 `N2`
3. 这条线可以作为辅助分析写进论文，但不应作为论文主方法核心

### 阶段四：验证复杂替代路线是否值得继续（round9-round11）

这一阶段的作用，本质上是“收尾”和“排除法证明”。

#### round9：RT-DETR-L 对比验证

结果：

- `RT-DETR-L @800 mAP50-95 = 0.3244`
- 比 `N2` 低 `0.0282`

同时它还有两个明显问题：

1. 更重
2. 更慢

因此 round9 可以得出很强的对比性结论：

- **更复杂的检测架构并没有在该任务上带来更优表现**
- 轻量 YOLO 主线依然更合理

#### round10：注意力模块方法矩阵

`A1/A2/A3` 都是 `P3-ECA attention` 的单点插入尝试。

最好的是 `A1`：

- `mAP50-95 = 0.281828`
- 比 `N2` 低 `0.070737`

这是非常强的负结果证据：

- 轻量注意力模块并没有改善任务表现
- 反而可能扰乱原有高效特征流

这对论文很有价值，因为可以说明：

- 你不是没试过模块增强
- 而是**系统试过之后，证据不支持它作为主方向**

#### round11：missing-rivet 过采样

目标是提升最难的小类 `missing-rivet`。

结果：

- `O1/O2/O3` 全部没有超过 `N2`
- 最好 `O3 mAP50-95 = 0.341244`
- 比 `N2` 低 `0.011321`

更关键的是：

- 连 `missing-rivet AP50-95` 也没有超过 `N2`

这说明：

1. 问题不只是“样本曝光次数不够”
2. 简单重复图像无法替代更高质量的数据分布优化

因此 round11 的价值，是把“类别不平衡补偿”这条路也做了封口。

## 5. 从实验中提炼出的最终学术结论

这部分最适合直接进论文“实验结论”或“讨论”章节。

### 结论 1：该任务的关键瓶颈不在于网络复杂度，而在于缺陷细节保真

所有复杂结构线基本都失败了：

- `WTConv`
- `NWD`
- `P2` 小目标头
- `P3-ECA attention`
- `RT-DETR-L`

这说明对该数据集而言，真正限制性能的不是“模型容量不够”，而更可能是：

1. 缺陷目标本身极小
2. 纹理信号弱
3. 标签质量和图像分布噪声明显
4. 过强增强容易破坏原始判别线索

### 结论 2：提高输入分辨率是有效的，但存在合理上限

`640 -> 800` 有帮助，说明小缺陷确实受益于更高像素表达；
但继续推到 `960` 并未形成继续提升，说明：

- 更高分辨率不是无上限收益
- 需要在显存、训练稳定性、尺度收益之间平衡

对本任务而言，`800` 是最合适的分辨率平衡点。

### 结论 3：关闭破坏局部纹理的强增强，是最关键的有效改动

`N2` 的成功证明：

- `mosaic`
- `erasing`
- 激进自动增强

并不总适合缺陷检测，尤其不适合：

1. 缺陷尺度小
2. 纹理细微
3. 边界模糊
4. 类间差异依赖微小表面变化

这条结论具有明确可迁移性，是论文里最值得强调的工程经验。

### 结论 4：标签清洗有价值，但在现有数据规模下不足以改写主线

`round6-8` 说明：

- 清洗后结果确实比某些不稳定分支更好
- 说明数据噪声客观存在

但同时：

- 清洗带来的收益没有稳定超过 `N2`
- 继续扩大 targeted cleanup 的边际收益明显下降

因此可以得出更稳妥的结论：

- **数据清洗是必要辅助工作，但不是当前阶段决定性突破来源**

### 结论 5：简单的类别过采样无法解决 missing-rivet 难类问题

`round11` 表明：

- 直接重复含 `missing-rivet` 的训练图像，并不能有效提升该类 AP

说明 `missing-rivet` 的困难，不仅是数量问题，还可能涉及：

1. 外观弱纹理
2. 标注一致性不足
3. 与背景/正常铆钉的边界区分困难

这为后续工作留出了更合理的方向：不是继续机械重复样本，而是考虑更高质量标注、难例挖掘或更细粒度类别建模。

## 6. 最适合论文的主线叙事

如果从论文表达效果考虑，我强烈建议不要把主线写成“尝试了很多模块，最后发现都不行”，而要写成下面这种更成熟的逻辑：

### 建议主线标题思路

**面向飞机蒙皮细粒度缺陷检测的轻量化 YOLO 优化研究：基于分辨率与细节保真训练策略的实验分析**

或者更直接一点：

**面向飞机蒙皮缺陷检测的 YOLO11n 训练策略优化与实验研究**

### 建议主线叙事顺序

1. 先说明任务特点
   - 缺陷目标小
   - 纹理弱
   - 类间差异细微
   - 数据集存在一定噪声与不平衡
2. 再说明问题意识
   - 通用检测默认增强和复杂结构改造，未必适合这类细粒度工业缺陷
3. 然后用实验逐步验证
   - 先建基线
   - 再测分辨率
   - 再测小目标头/结构增强
   - 最后收敛到训练策略与数据质量分析
4. 最终给出核心结论
   - 与其增加模型复杂度，不如控制增强破坏、保留缺陷细节
   - `N2` 是当前任务上综合最优解

这个叙事的优点是：

1. 逻辑自然
2. 有问题驱动
3. 有“正结果”也有“负结果”
4. 显得你不是盲目试模型，而是在做有判断的实验收敛

## 7. 论文正文建议怎么写

### 7.1 方法章节不要写成“我提出了一个超级新结构”

从现有结果看，这篇论文最不适合的写法是：

- 强行包装一个复杂改进网络作为主创新

因为实验不支持。

更适合的写法是：

- 以 `YOLO11n` 为基础检测器
- 围绕飞机蒙皮缺陷任务特点，研究输入尺度、数据增强策略、数据清洗方式、替代结构和类别平衡策略对性能的影响
- 最终形成一套轻量、稳定、可复现的检测配置

这会更真实，也更稳。

### 7.2 结果章节建议分成三大段

#### 第一段：主线增益实验

放：

- `B0`
- `R1`
- `N2`

这三者构成最核心主表。

想表达的是：

- 基线建立
- 分辨率提升有效
- 训练增强策略优化进一步带来最优结果

#### 第二段：失败但有价值的对比实验

放：

- `T1`（P2 小目标头）
- `A1`（注意力模块）
- `D1/RT-DETR-L`

这部分用来说明：

- 并不是所有“看起来更先进”的方法都适合该任务
- 任务特征决定了方法选择

#### 第三段：数据质量与类别分布实验

放：

- `F2`
- `G2`
- `H2`
- `O3`

想表达的是：

- 数据预处理和清洗有一定局部帮助
- 但未能稳定超越主线模型
- 数据层修补存在收益上限

> 本文围绕飞机蒙皮三类缺陷检测任务，系统开展了从基线构建、输入分辨率优化、训练增强策略调整、结构模块改造、数据清洗到类别再平衡的多轮实验研究。实验结果表明，在该类细粒度、弱纹理、小目标工业缺陷检测场景中，检测性能的提升主要依赖于对缺陷细节信息的保留，而非网络结构复杂度的增加。相较于官方 YOLO11n 基线，采用 800 输入分辨率并关闭 mosaic、erasing 等强扰动增强的 `N2` 配置取得了全流程最优的综合性能，说明弱纹理缺陷检测对训练策略的敏感性高于对复杂结构改造的依赖。
