# aircraft_ai_dataset_round13 精简补跑方案

## 1. 结论先行

`round1-round12` 的结果已经足够明确：

- 最终锚点仍然是 `N2`：`YOLO11n + imgsz=800 + 关闭 mosaic/erasing/强增强`
- `round12` 里最接近 `N2` 的不是 patch，也不是 sliced inference，而是 `S2` 切片训练：`mAP50-95 = 0.344840`
- `S2` 距离 `N2` 只差 `0.007725`
- `S3`、`P2` 都没有证明“再叠加数据技巧就会自然反超”

因此，下一批实验不应该再开新方向，而应该只保留 **2 到 3 条最可能补齐这 `0.005~0.01` 差距** 的线。

---

## 2. 建议只保留的 3 条线

### 线 1：只做 `S2` 的参数纠偏，不再做新切片家族

这是下一批里优先级最高的一条线。

`S2` 已经说明“切片训练”本身不是错方向，问题更可能出在：

- `slice_size=512` 让上下文丢得有点多
- `overlap=0.20` 可能引入了重复目标和边界扰动
- 训练只看切片，可能让模型对整图语境理解偏弱

这一条线不再验证“切片是否有用”，而是验证：

> `S2` 没超过 `N2`，到底是因为切片思路本身不行，还是因为当前切片参数不合适。

#### 建议实验

| 编号 | 方案 | 目的 |
| --- | --- | --- |
| R13-S2a | `slice=640, overlap=0.15` | 增加上下文，减少重复区域 |
| R13-S2b | `slice=640, overlap=0.20` | 检查更大切片是否直接优于 `512` |
| R13-S2c | `slice=512, overlap=0.10` | 检查当前方案是否被过高重叠拖累 |

#### 为什么这条线最值得跑

- 它已经是目前新路线里离 `N2` 最近的一条
- 改的是参数，不是方法论，实验可解释性强
- 如果 `640` 切片能补回上下文，最有机会直接追平甚至小幅超过 `N2`

#### 预期

- 保守预期：`0.345 ~ 0.351`
- 乐观预期：`0.352 ~ 0.358`

---

### 线 2：做 `fit-within + slice-train` 组合，而不是继续单跑 patch

这条线的逻辑是“把前面两条最接近正确答案的思路合并”。

已有证据是：

- `round5` 的 `fit-within` 虽然没超过 `N2`，但对 `missing-rivet` 有局部收益
- `round12` 的 `S2` 虽然没超过 `N2`，但对 `scratch` 和整体 recall 更接近可用

这说明两者可能分别在解决不同问题：

- `fit-within`：尽量保住原图缩放时的小目标比例关系
- `slice-train`：让局部缺陷在输入中获得更多有效像素

如果这两条线是互补的，那么真正该补跑的不是继续扩 patch，而是测试：

> 细节保真的导出方式，能不能让切片训练的收益真正释放出来。

#### 建议实验

| 编号 | 方案 | 目的 |
| --- | --- | --- |
| R13-FS1 | `F2/fit-within dataset + slice=640, overlap=0.15` | 主推组合线 |
| R13-FS2 | `F2/fit-within dataset + slice=512, overlap=0.10` | 验证组合是否依赖更小切片 |

#### 为什么不再优先跑 patch

- `P2` 已经证明“直接补贴片”在当前规则下没有带来反超
- patch 更容易引入分布漂移，论文解释成本也更高
- `fit-within + slice` 属于同一条“细节保真”主线，更容易写成一套完整方法逻辑

#### 预期

- 保守预期：`0.346 ~ 0.351`
- 乐观预期：如果两者互补，可能冲到 `0.353+`

---

### 线 3：只做低成本 loss 微调，不再动大结构

如果前两条线是“最可能真正涨点”的主线，那么第三条线应该只承担一个任务：

> 用最低成本去抠最后 `0.002~0.006` 的定位精度。

这里不建议再做任何新模块，只动 bbox 回归损失。

#### 建议实验

| 编号 | 方案 | 目的 |
| --- | --- | --- |
| R13-L1 | `N2 + Wise-IoU` | 直接看原主线能否低成本涨点 |
| R13-L2 | `best slice candidate + Wise-IoU` | 如果切片线接近 `N2`，尝试补最后一点差距 |
| R13-L3 | `N2 + SIoU 或 EIoU` | 作为单个补充对照 |

#### 为什么这条线保留、但排第三

- 它单独翻盘的概率不如前两条
- 但成本低，且非常适合做“最后一脚”
- 如果某个切片变体已经到 `0.350+`，loss 微调最有机会把它推过 `N2`

#### 预期

- 单独收益通常只有 `+0.002 ~ +0.008`
- 但如果叠加在最优切片候选上，可能正好跨过 `N2`

---

## 3. 明确不再优先补跑的方向

下一批建议暂停以下路线：

- `SAHI / sliced inference only`
  - `S1` 已经证明只改推理会带来大量误检
- `mixed original + slice train`
  - `S3` 比 `S2` 更差，优先级应低于切片参数纠偏
- `patch copy-paste`
  - `P2` 已给出负结论，除非重写生成规则，否则先不继续
- `attention / P2 head / RT-DETR / 新结构模块`
  - `round1`、`round3`、`round9`、`round10` 已经基本完成证伪
- `简单过采样`
  - `round11` 已证伪

---

## 4. 最终建议的补跑顺序

如果只想保留最有希望的两三条线，建议按下面顺序执行：

### 第一优先级：一定要跑

1. `R13-S2a: slice=640, overlap=0.15`
2. `R13-S2b: slice=640, overlap=0.20`
3. `R13-S2c: slice=512, overlap=0.10`

这三组的任务是先回答一个核心问题：

> `S2` 没赢，是切片思路不对，还是切片参数没调到位。

### 第二优先级：只有当第一组接近或追平 `N2` 时再跑

4. `R13-FS1: fit-within + slice=640, overlap=0.15`
5. `R13-FS2: fit-within + slice=512, overlap=0.10`

### 第三优先级：只作为补刀实验

6. `R13-L1: N2 + Wise-IoU`
7. `R13-L2: best slice candidate + Wise-IoU`

---

## 5. 如果你只能跑 3 组

那就只跑这 3 组：

1. `R13-S2a: slice=640, overlap=0.15`
2. `R13-S2b: slice=640, overlap=0.20`
3. `R13-L1: N2 + Wise-IoU`

原因很简单：

- 前两组是对最有希望路线的直接纠偏
- 第三组是最低成本、最可能捡到最后一点 mAP 的补充

---

## 6. 论文主线怎么写会最顺

如果下一批里有结果超过 `N2`，最顺的论文主线将变成：

> 在飞机蒙皮细粒度缺陷检测任务中，单纯堆叠复杂结构难以稳定提升性能；相比之下，围绕缺陷细节保真的输入组织方式更有效。本文在 `YOLO11n` 轻量基线基础上，通过高分辨率训练、关闭破坏细节的强增强，并进一步探索切片训练参数与细节保真导出策略，验证了提升缺陷有效像素占比与保留真实局部纹理对检测性能的关键作用。

如果下一批仍没有超过 `N2`，论文也依然成立，而且论证会更扎实：

> 本文系统比较了结构增强、数据清洗、过采样、切片训练、贴片增强等多条优化路线。结果表明，在当前公开飞机蒙皮三分类数据集上，轻量模型配合细节保真训练策略已经接近该任务的有效上限；进一步复杂化输入组织或网络结构，难以带来稳定收益。

---

## 7. 最终一句话建议

下一批不要再“广撒网”了。

只保留这三条：

1. `S2` 切片参数纠偏
2. `fit-within + slice-train` 组合验证
3. `Wise-IoU` 级别的低成本回归微调

其中真正最值得优先跑的，是 **更大切片 + 更低 overlap 的 `S2` 精修线**。
