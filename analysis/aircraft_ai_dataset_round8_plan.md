# Aircraft AI Dataset 第八轮实验方案

## 1. 本轮目标

第七轮已经证明两件事：

- 固定 `N2` 配方、只做标签清洗，比 `round6/C1` 这条“清洗后再 focus-crop”更合理
- 但 `G2` 仍未超过 `N2`，说明当前公开 3 类数据集已经接近收益上限

因此第八轮不再引入任何新的训练技巧，而是把公开数据集的最后一次验证收缩成一个更明确的问题：

**当我们把定向清洗样本池扩大到 `50-150` 张训练高风险样本，并继续保持 `N2` 配方不变时，能否拿到一次“有实际意义的提升”？**

## 2. 实验编号

| 编号 | 数据 | 配方 | 作用 |
| --- | --- | --- | --- |
| `H1` | `manual_clean_v2_targeted72` | `N2` | round8 主实验，扩展到约 `72` 张 train 高风险样本 |
| `H2` | `manual_clean_v3_targeted90` | `N2` | round8 自动续跑候选，当 `H1` 没有形成实际提升时再继续 |

## 3. 清洗范围

本轮继续保持“只改训练集，不改验证/测试集”。

清洗对象只看高风险标签：

1. 极小框
2. 宽高接近点状、边界极不稳定的框
3. 明显更像噪声点而不是缺陷实体的框
4. `missing-rivet` / `scratch` / `rust` 中 tiny-box ratio 异常偏高的样本

本轮自动化采用上一轮已经验证过的清洗策略：

- 如果样本被 `tiny_box_ratio` 命中，就移除其中满足 tiny 阈值的框
- `dense_boxes` 样本默认保留，只做记录，不自动删框
- `valid/test` 不参与清洗

## 4. 样本池策略

### `H1`

- `limit = 150`
- `area_small = 0.0020`
- `dim_small = 0.030`
- `boxes_dense = 20`
- `small_ratio_suspicious = 0.30`

预期会筛出大约 `72` 张训练高风险样本，属于“更大规模但仍可控”的一次正式验证。

### `H2`

- `limit = 150`
- `area_small = 0.0020`
- `dim_small = 0.030`
- `boxes_dense = 18`
- `small_ratio_suspicious = 0.25`

这是一档更激进的补充策略，只在 `H1` 没有形成实际提升时才自动继续。

## 5. 实际提升判据

自动控制器采用“先看主指标，再看目标类”的规则。

相对于当前最佳清洗分支 `G2`，满足任一条件即视为“有实际提升”：

1. `mAP50-95` 提升至少 `0.001`
2. `mAP50-95` 不下降，同时 `missing-rivet AP50-95` 提升至少 `0.002`

同时保留一个约束：

- 如果 `scratch AP50-95` 明显下降超过 `0.010`，则不把它视为健康提升

## 6. 自动续跑停止条件

自动化不会无限制地跑下去，而是采用有边界的闭环：

1. 若当前阶段已经达到“实际提升”，自动停止，并把该阶段记为当前最佳清洗方案
2. 若当前阶段没有提升，则自动进入下一阶段
3. 若所有预设阶段都跑完仍无提升，则自动停止，并给出“公开 3 类数据集基本饱和”的结论
4. 若某阶段超过 `N2`，也立即停止，因为公开数据集主锚点已经被刷新

## 7. 自动化流程

### 准备阶段

`prepare_aircraft_ai_round8.py`

- 按阶段参数生成 targeted review summary
- 复制 review pack
- 应用 train-only tiny-box 清洗策略
- 生成对应 cleaned dataset

### 训练阶段

`run_aircraft_ai_round8.py`

- 只运行指定阶段的实验
- 自动汇总到 round8 结果表
- 训练后刷新 round8 summary

### 控制阶段

`run_aircraft_ai_cleanup_autoloop.py`

- 以 `G2` 为当前清洗主锚点
- 依次执行 `H1 -> H2`
- 每轮结束后自动读取结果 CSV
- 按“实际提升判据”决定是否停止或进入下一阶段

## 8. 预期结论

第八轮有三种可能结论：

1. `H1` 或 `H2` 对 `G2` 形成实际提升
   说明扩大定向清洗样本池仍然有价值，公开 3 类数据集还有最后一小段数据侧增益可挖
2. `H1/H2` 仍优于 `C1`、但不能稳定超过 `G2`
   说明这条线已经接近饱和，后续不建议再继续投入公开集
3. `H1/H2` 最终超过 `N2`
   说明“固定 `N2` 配方 + 扩大量级定向清洗”才是公开 3 类数据集的最佳终版方案
