# MECHLAB | 机械结构工程师面试训练营

可访问的交互式中文机械结构工程师面试学习网站。

## 功能

- 16 个专题，覆盖机械原理、材料、工艺、热处理、工程图与公差、电机、气动与真空、丝杆与直线模组、皮带与链条、齿轮和减速器、导轨轴承、传感器、输送设备、SolidWorks、综合项目追问。
- 全文关键词搜索、专题筛选、展开参考答案与一行速记。
- 自测记忆卡、10 题模拟面试、自评结果、错题本、收藏题目。
- 丝杆垂直升降驱动转矩、气缸理论推力、真空吸盘吸附力、电机功率转矩的交互计算器。
- 三日冲刺计划、公式速查；自动使用浏览器 localStorage 保存进度，并支持 JSON 导入导出。
- 纯 HTML/CSS/JS，无外部构建依赖，移动端与桌面均可使用。

## 快速运行

直接用浏览器打开 `index.html`，或使用任意静态网站服务器在此目录发布。

## 知识来源与边界

内容围绕用户提供的《机械结构工程师面试题（最新）》材料涉及的基础主题组织，并补充了机械与自动化工程基础、常见选型思路、现代面试项目问题；**这不是逐题逐字从原 PDF 提取的内容，也不是 PDF 的原书转录**。请根据适用 GB/ISO 标准、厂家手册和实际工况核实设计尺寸、公差、寿命、扭矩与安全要求。部分计算器刻意采用简化物理模型，不能直接作为工程安全选型依据。

## 代码结构

- `index.html`：页面容器
- `style.css`：响应式暗色 UI
- `questions.js`：题库、公式和复习计划
- `app.js`：导航、搜索、卡片、面试、计算器和学习进度

## 维护

添加题目：在 `questions.js` 的 `DATA` 对应模块下新增 `[问题, 参考回答, 速记要点]`。题目 ID 会按模块顺序重新分配，因此已保存进度对应 ID 的稳定性取决于题目插入顺序；正式长期运营时建议为题目指定固定 ID。
